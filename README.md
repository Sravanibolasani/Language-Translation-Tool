
# Language Translation Tool 🌍

A simple and user-friendly web application that translates text between multiple languages using the MyMemory Translation API.

## Features

- Translate text between multiple languages.
- Supports English, Hindi, Telugu, Tamil, French, Spanish, German, Japanese and more.
- Character counter.
- Swap source and target languages.
- Copy translated text.
- Clear input and output.
- Listen to translated text using text-to-speech.
- Supports longer text through smaller translation requests.
- Responsive design for mobile and desktop.
- Error handling for API connection issues.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- MyMemory Translation API
- Web Speech API

## How to Run

1. Download or clone the project from GitHub.
2. Open the project folder in VS Code.
3. Open `index.html` using a browser or Live Server.
4. Select the source language.
5. Select the target language.
6. Enter the text you want to translate.
7. Click the Translate button.
8. Copy or listen to the translated text.

## API Information

This project uses the MyMemory Translation API to translate text.

API:
https://api.mymemory.translated.net/

No local translation server is required.

The API is subject to usage limits and language availability. Translation quality may vary.
